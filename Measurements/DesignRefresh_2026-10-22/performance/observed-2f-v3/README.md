# Observed 2f v3 application performance

This is a derived public summary of the fixed old application/source states, not a replay bundle or an acceptance result. The primary cohort is the complete 12-block AA/AB study: 96 native slots in each arm, 192 total, 64 cycles per process, the exact v3 source/compiled identities and SDK 2f, and original-UI baseline v7. `cohorts.json` retains both complete 12-row comparison objects and every 24-value controlDrift array. The retained independent reference audit matched both comparison hashes with 7,988 checks.

AB records eight flagged command, owner-CPU and memory rows. The host was not established quiet or exclusive, and timing/CPU/private-memory same-side controls were unstable. All flags and unfavorable controls remain visible. Neither collection completion nor the numerical audit approves policy, establishes non-regression, accepts a cost, or attributes a cause. A later optimization requires its own exact-source qualification and measurement.

The two 2-block/32-cycle diagnostics are separate 16-slot studies, each with a retained 3,541-check audit. They describe v3 and the outline-publication repair respectively. Phase CPU/wall and other numeric medians are derived from the original arrays: first a median for each native slot, then a median of the four slot medians per view and side within that diagnostic. Per-slot values and sample counts remain available. The diagnostics are not pooled with each other or the primary study and do not establish statistical benefit.

Four separate resource-investigation reports are hash-referenced but their metrics are omitted. Their work/image instrumentation and snapshot phases differ; the same nominal fixture name or source-unit count does not make them substitutes for primary memory observations.

`rawNativeSlots` gives all 224 actual primary/diagnostic slot names with original byte lengths and SHA256 values. `originalMetadataInventory` additionally references every ordinary file under the four exact retained collection/investigation trees and selected freeze/audit records. Original producer files remain private and untouched. The public JSON excludes raw arrays, study/environment payloads, host process identities, absolute paths and binaries. Binary identities are quoted from retained receipts, not rehashed here. Hash references support integrity review; this packet cannot independently replay absent private arrays and binaries. No physical presentation, input, scheduler or GPU attribution is claimed.
