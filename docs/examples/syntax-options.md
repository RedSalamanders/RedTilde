# Optional Markdown syntax

Each family below has its own switch in **Settings → Markdown syntax**. Switch
one off to inspect its literal source, then on to restore its native rendering.
The source, selection, and undo history stay the same.

## Inline additions

The ==important observation== is highlighted.

The area is x^2^, and the molecule is H~2~O.

The ++newly inserted sentence++ belongs in the next draft.

## Wiki links

An ordinary wiki link is [[Field notes]]. A labeled link is
[[Field notes|the observation notebook]]. They remain inert references;
target navigation and embedded documents are not implemented.

## Definition lists

Observation
: A recorded measurement and its context.

Review
: A second reading that checks the first conclusion.

## Abbreviations

The API and UI descriptions refer to invented notebook tools.

*[API]: Application programming interface
*[UI]: User interface

## Always-on GFM

**Strong**, *emphasis*, ~~strike~~, tables, task lists, and autolinks belong to
the base Markdown profile, rather than these seven optional switches.

- [x] Inspect one family at a time
- [ ] Undo a source edit after switching views
