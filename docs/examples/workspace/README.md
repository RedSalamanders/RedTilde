# Lantern folder notebook

Choose **File → Open Folder...** and select this `workspace` folder. The Files
pane lists its Markdown documents and folders, including `.markdown` files.

1. Expand **notes** and open **meeting.md**.
2. Open **research.markdown** in the same folder.
3. Expand **guides** and open **writing.md**.
4. Create an untitled document or open a file elsewhere. The root stays here.
5. Close RedTilde and open it again. The chosen folder returns.

Folder selection leaves unsaved writing untouched. Opening a different file
still prompts before discarding edits. Use **Open Folder...** to change the root.
