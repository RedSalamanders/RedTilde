# Native editing qualification — completed local software scope

T-U1's Source Enter, native text-store capacity and quoted file-paste software
checks are complete through the exact adopted API-4 SDK. Four maintained cases
exercise the actual hidden application and the app-owned native ACP component,
including line endings, capacity rejection, preview/mirror preservation, history,
notifications and teardown. They use no OS clipboard or foreground takeover.

The lasting behavior belongs to [editing](../../Editor/Editor_Markdown.md) and
[validation](../../Testing/Testing_Validation.md); the [usage guide](../../../docs/README.md)
documents the limits. The [evidence record](../../../Measurements/NativeEditing_2026-11-07/README.md)
binds original sources, binaries, symbols and runtime archives to all six clean
builds. Each x64 profile passes 143 cases and 38 captures and retains the actual
Win32 1314 symbolic-link failure. Actual ASan and interrupted-write restart pass.

The initial hidden-HWND fixture and ARM64 WRL warning build remain rejected and
retained. ARM64 native runtime, current hosted/production acceptance, physical
input/AT, performance and application API-5 adoption stay in the parent plan.
