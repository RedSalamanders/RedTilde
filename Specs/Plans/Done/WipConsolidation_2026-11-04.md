Original failed runs, receipts, symbols, datasets and proposal images retain their owners. Only explanatory Markdown links are repaired; raw JSON/log/CSV/PNG evidence is not rewritten. Archived finding appendices remain reference detail, not independent active plans. Existing Done history changes only where a moved local link requires repair. No runtime source, SDK pin, release, visibility, branch cleanup, history rewrite or interactive test is part of this consolidation.
