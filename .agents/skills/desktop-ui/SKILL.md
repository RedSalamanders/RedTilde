---
name: desktop-ui
description: Revise RedTilde native layout, contextual commands, live appearance and keyboard or UIA behavior.
---

Read [the design system](../../../Specs/UI/UI_DesignSystem.md) and editor contract. Keep writing dominant;
group structure/inline/insertion actions and use optional outline/context tools. Work with the native host's
focus and UIA services. A painted imitation of a button is not an accessible command. Preserve selection while
menus open, route arrows/Tab/Esc/Enter to the displayed surface, and return focus. Respect high contrast,
reduced motion, 800x560 minimum and 150/200% DPI. Apply preferences to the running window. Validate actual
app-harness captures; real desktop focus/IME acceptance requires the person's agreed time.
