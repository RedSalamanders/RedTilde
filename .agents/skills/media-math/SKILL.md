name: media-math
description: Add or verify local images, native in-document math and supported Mermaid diagrams in RedTilde.
---

Read [the editor contract](../../../Specs/Editor/Editor_Markdown.md) and the exact pin's rich-text guide.
Take image requests after preparation, authorize explicit paths, decode on a COM-initialized worker and marshal
completion to the owner. Bound queues/pixels and reject cancelled or foreign tokens. Network access is opt-in;
missing/unsupported resources retain alt/source. Use the exact pin's named bounded native profiles as documented
in its rich-text guide; unsupported syntax and directives remain fenced source. Math is a native source-backed inline/display object,
using the library parser and renderer in both document and read-only inspector. Keep F2 source access, source
selection/history and diagnostics. Do not advertise full LaTeX/Mermaid compatibility. Test matrices, simultaneous
scripts, delimiters, malformed/deep/capacity input, view changes, undo and device loss.
